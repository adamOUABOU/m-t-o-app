# Météo par ville

[Voir la démo en ligne](https://adamouabou.github.io/m-t-o-app/)

Application HTML, CSS et JavaScript. Elle recherche les coordonnées d’une ville, puis affiche la température actuelle, l’humidité et le vent avec Open-Meteo.

Ouvrir `index.html` dans un navigateur, saisir une ville et cliquer sur **Rechercher**. Les données nécessitent une connexion Internet.
